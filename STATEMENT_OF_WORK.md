# Statement of Work: USDC Payment Gateway (WDK Edition)

## Project Overview
A production-ready REST API integrating Tether's WDK for self-custodial wallet management. Accepts USDC payments on Ethereum Sepolia testnet.

## Technical Stack
- Node.js (v24)
- TypeScript
- Tether WDK (@tetherto/wdk, @tetherto/wdk-wallet-evm)
- ethers.js (v6)
- Native HTTP Server

## Current Status
